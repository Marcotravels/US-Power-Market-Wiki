# 电力市场类型：日前市场与实时市场

> **English:** Electricity Market Types: Day-Ahead vs Real-Time Markets

## 概述

电力市场分为多个时间维度的交易类型，其中最重要的是**日前市场（Day-Ahead Market）** 和**实时市场（Real-Time Market）**。这两个市场共同构成了电力批发市场的核心，帮助确保电力的可靠供应和价格发现。

## 为什么需要多个市场？

电力具有几个独特属性，使得多市场结构成为必要：

1. **电能不能大量存储** — 必须实时发用平衡
2. **输送受物理限制** — 输电能力有限
3. **需求波动大** — 随时间、天气、季节变化
4. **供给侧多元** — 火电、核电、风电、太阳能等特性各异

## 日前市场（Day-Ahead Market）

### 什么是日前市场？

日前市场是电力批发市场的第一个环节，参与者在**实际供电前一天**进行电力买卖交易。市场出清后，形成次日的发电计划和日前价格。

### 日前市场的时间线

| 时间点 | 事件 |
|--------|------|
| T-1天 12:00 | 市场参与者提交次日投标（Bid）和报价（Offer） |
| T-1天 13:00-16:00 | 市场出清（Market Clearing） |
| T-1天 16:00后 | 公布次日24小时的发电计划和日前价格 |
| T日 | 按照日前计划执行发电 |

### 日前市场的功能

1. **价格发现（Price Discovery）**
   - 形成次日的"预期价格"
   - 为市场参与者提供价格信号

2. **风险管理（Risk Management）**
   - 参与者可以锁定次日价格
   - 减少实时市场的价格波动风险

3. **机组组合（Unit Commitment）**
   - 确定哪些发电机组需要启动
   - 提前安排备用容量

4. **输电计划（Transmission Scheduling）**
   - 基于日前价格安排输电路径
   - 避免输电拥堵

### 日前出清（Day-Ahead Clearing）

市场出清过程考虑以下约束：

- **发电约束：** 机组最小/最大出力、爬坡速率、启停时间
- **输电约束：** 线路热极限、电压限制
- **系统约束：** 备用要求、频率响应要求

### 日前价格（LMP）

**节点边际电价（Locational Marginal Pricing, LMP）** 是日前市场的核心价格机制。

**LMP的三个组成部分：**

```
LMP = 能量价格 + 阻塞成本 + 损耗成本
```

| 组成部分 | 英文 | 解释 |
|---------|------|------|
| 能量价格 | Energy Component | 边际发电成本 |
| 阻塞成本 | Congestion Component | 输电阻塞导致的额外成本 |
| 损耗成本 | Loss Component | 输电损耗导致的额外成本 |

## 实时市场（Real-Time Market）

### 什么是实时市场？

实时市场是**实际供电时刻**进行交易的市场，用于调整日前计划与实际运行之间的偏差。在美国主要ISO/RTO中，实时市场通常每5分钟出清一次。

### 实时市场的时间线

| 时间点 | 事件 |
|--------|------|
| T日 0:00-24:00 | 实时运行，每5分钟出清一次 |
| 实时 | 根据实际负荷、发电、输电情况调整 |
| T+1 | 结算实时偏差和实时价格 |

### 实时市场的功能

1. **实时平衡（Real-Time Balancing）**
   - 调整发电以匹配实际负荷
   - 维持系统频率在60Hz

2. **偏差调整（Deviation Settlement）**
   - 处理日前计划与实际的偏差
   - 按实时价格结算

3. **辅助服务（Ancillary Services）**
   - 调频服务（Regulation）
   - 旋转备用（Spinning Reserve）
   - 调峰服务（Load Following）

4. **紧急响应（Emergency Response）**
   - 处理意外机组停运
   - 应对负荷突变

### 实时价格

实时价格基于**实时系统边际成本**，通常比日前价格更波动。

**影响实时价格的因素：**
- 实时负荷与预测的偏差
- 发电机组的实际出力
- 输电线路的实际拥塞情况
- 辅助服务的需求

## 两大市场对比

| 特征 | 日前市场 | 实时市场 |
|------|---------|---------|
| 交易时间 | 提前1天 | 实时（实时前5-60分钟） |
| 出清频率 | 每天1次 | 每5分钟1次 |
| 价格类型 | 24小时分段价格 | 每5分钟价格 |
| 主要目的 | 计划、风险锁定 | 偏差调整、实时平衡 |
| 参与者 | 发电商、负荷聚合商、零售商 | 主要为调度机构 |
| 价格波动 | 相对稳定 | 波动较大 |

## 市场之间的联系

### 财务结算流程

```
1. 日前市场
   - 买卖双方达成交易
   - 锁定次日各时段的买卖量和价格
       ↓
2. 实时运行
   - 实际发电和负荷与日前计划有偏差
   - 调度机构进行实时平衡
       ↓
3. 结算
   - 偏差 = 实际 - 日前
   - 偏差按实时价格结算
```

### 偏差（Deviation）

- **如果实际发电 > 日前计划：** 卖方获得额外收入
- **如果实际发电 < 日前计划：** 卖方需要购买偏差电量
- **如果实际负荷 > 日前计划：** 买方需要购买额外电量
- **如果实际负荷 < 日前计划：** 买方获得退款

## 美国的实践

### 各ISO/RTO的市场结构

| ISO/RTO | 日前市场 | 实时市场 | 特点 |
|---------|---------|---------|------|
| CAISO | ✓ | ✓ | 既有日前也有实时 |
| ERCOT | ✗ | ✓ | 只有实时市场（QSE系统） |
| PJM | ✓ | ✓ | 成熟的日前+实时 |
| ISO-NE | ✓ | ✓ | 完善的节点定价 |
| MISO | ✓ | ✓ | 涵盖15个州 |
| SPP | ✓ | ✓ | 覆盖中西部 |

### ERCOT的特殊性

**ERCOT是唯一没有日前市场的主要ISO/RTO）**

原因：
- ERCOT是"可靠性"市场，不是"财务"市场
- 主要通过实时市场（和安全约束经济调度）运行
- 依赖"合格调度实体（QSE）"系统进行日前计划

## 对可再生能源的意义

### 日前市场的作用

- 可再生能源开发商可以通过日前市场锁定价格
- 预测次日风光出力，提前出售电力

### 实时市场的作用

- 风光出力偏离预测时，通过实时市场调整
- 储能可以在实时市场中提供灵活性
- 负电价时段，储能充电赚取收益

### 鸭子曲线与市场影响

在加州等高太阳能渗透地区，"鸭子曲线"导致：

1. **中午低价：** 太阳能发电高峰，电力供过于求
2. **傍晚高价：** 太阳能骤降，需求高峰（"颈部"）
3. **快速爬坡需求：** 需要快速增加的灵活资源

这种模式深刻影响了日前和实时价格走势。

## 辅助服务市场

实时市场还包括多个辅助服务子市场：

| 服务类型 | 英文 | 功能 |
|---------|------|------|
| 调频 | Regulation | 自动发电控制，维持频率 |
| 旋转备用 | Spinning Reserve | 10分钟内可响应的备用 |
| 非旋转备用 | Non-spinning Reserve | 10-30分钟可响应的备用 |
| 调峰 | Load Following | 应对小时级负荷变化 |
| 频率响应 | Frequency Response | 一次调频，自动响应 |

## 相关概念

- **LMP：** Locational Marginal Pricing（节点边际电价）
- **SCED：** Security Constrained Economic Dispatch（安全约束经济调度）
- **SCUC：** Security Constrained Unit Commitment（安全约束机组组合）
- **Bid/Offer：** 投标/报价
- **Clearing：** 市场出清
- **Congestion：** 输电阻塞
- **Loss：** 输电损耗
- **Spread：** 日前与实时价格的价差
- **Negative Pricing：** 负电价
