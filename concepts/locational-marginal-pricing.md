# 电力市场节点定价机制

> **English:** Locational Marginal Pricing (LMP) — Nodal Pricing in Electricity Markets

## 概述

节点边际电价（Locational Marginal Pricing, LMP）是现代电力批发市场中最精细的价格机制。与传统区域统一定价不同，LMP 为电网中**每一个节点（Node）** 计算独立的价格，精确反映该位置在特定时刻的发电成本、输电阻塞成本和输电损耗成本。

LMP 是 PJM、CAISO、ISO-NE、MISO、SPP 等美国主要 ISO/RTO 的核心定价基础。ERCOT 是例外——它使用"系统边际价格"（System Marginal Price），不做节点定价。

---

## 为什么需要节点定价？

### 统一定价的缺陷

在理想电力市场中，如果输电网络无限通畅，所有位置的价格应该相同。但现实是：

```
输电线路有容量限制（热极限、电压、安全约束）
       ↓
电能不能自由流动
       ↓
不同位置的实际供电成本不同
       ↓
统一定价导致市场失灵
```

**一个简单例子：**
- 某地区西部有大量便宜风电，但输电线路容量不足
- 如果统一定价，东部用户支付的是西部低价，还是需要就地建高价电站？
- LMP 解决这个矛盾：西部用户按低价结算，东部用户按高价（包含阻塞成本）结算

### LMP 的核心优势

| 优势 | 解释 |
|------|------|
| **精确信号** | 每个位置的价格真实反映该地的边际供电成本 |
| **投资引导** | 高 LMP 区域提示需要新建发电或输电投资 |
| **阻塞透明** | 阻塞成本显性化，驱动市场主体自发优化 |
| **经济效率** | 激励供需双方在价格信号下调整行为 |
| **辅助服务联动** | 与辅助服务市场联合优化，整体效率最优 |

## LMP 的数学基础

### 经济学边际成本定价

LMP 源于经济学中的**边际成本定价原理**：

> LMP = 在满足所有安全和物理约束的条件下，向该节点额外增加 1 MW 负荷所需的系统最小成本增量

### LMP 的三个组成部分

```
LMP(n, t) = Energy Component(n, t) 
           + Congestion Component(n, t) 
           + Loss Component(n, t)
```

### 1. 能量价格（Energy Component）

能量价格是系统边际成本（System Marginal Cost），代表在最经济的调度下，多供 1 MWh 电力的边际发电成本。

**计算逻辑：**
```
假设系统中有三台机组：
  机组A（气电）：$50/MWh，容量充裕
  机组B（气电）：$80/MWh，容量充裕
  机组C（调峰）：$150/MWh，容量有限

当系统负荷较低时 → 调度机组A → 能量价格 ≈ $50/MWh
当系统负荷上升时 → 机组A满发，调度机组B → 能量价格跃升至 $80/MWh
当系统负荷极高时 → 机组B也满发，调度机组C → 能量价格跃升至 $150/MWh
```

能量价格是**全网统一的**（无阻塞时）。

### 2. 阻塞成本（Congestion Component）

阻塞成本反映了**输电约束对价格的影响**。当某条线路达到容量上限，电能无法从低价区自由流向高价区，导致不同区域价格分化。

**阻塞产生的原因：**
- 线路热极限（Line Thermal Limit）：电流过大导致导线发热
- 电压约束（Voltage Limit）：某节点电压过低或过高
- 稳定约束（Stability Limit）：系统动态稳定性要求

**阻塞成本的数学表达：**

```
设线路 l 的传输容量为 Cap_l
实际潮流 P_l > Cap_l 时（过载）
       ↓
影子价格（Shadow Price）λ_l > 0
       ↓
λ_l × 边际约束违反量 → 转化为 LMP 的阻塞分量
```

**直观理解：**
```
[低价风电区] ---输电线路容量满--> [高价负荷区]

无法输送的电 = 必须额外启动本地贵价机组
额外成本 = 阻塞成本

低价区 LMP = 系统边际成本（便宜）
高价区 LMP = 系统边际成本 + 阻塞溢价（贵）
```

### 3. 损耗成本（Loss Component）

电力在输电过程中有损耗（通常 2-5%）。LMP 需要补偿这部分损耗成本。

```
损耗分量 ≈ (节点到参考点的距离) × 单位损耗成本

靠近发电侧节点 → 损耗小 → 损耗分量为负 → LMP 略低
靠近负荷侧节点 → 损耗大 → 损耗分量为正 → LMP 略高
```

### 数值示例

```
某一时刻某节点的 LMP 计算：

能量分量：     $45.00/MWh    （系统边际成本）
阻塞分量：    +$12.50/MWh    （该区域输电受限）
损耗分量：     +$1.20/MWh    （输电损耗）
─────────────────────────────────
LMP =         $58.70/MWh
```

## 安全约束经济调度（SCED）

### 什么是 SCED？

SCED（Security Constrained Economic Dispatch）是计算 LMP 的核心算法。每 5 分钟，系统运行 SCED，计算满足所有约束条件下的最优发电计划，同时产出每个节点的 LMP。

### SCED 解决的问题

```
最小化：Σ(发电成本_i × 出力_i)

约束条件：
  1. 功率平衡：Σ 发电 = Σ 负荷 + 总损耗
  2. 发电容量：出力_min ≤ 出力 ≤ 出力_max
  3. 爬坡限制：|Δ出力| ≤ 爬坡速率 × Δt
  4. 输电约束：|P_l| ≤ Cap_l（每条线路）
  5. 电压约束：V_min ≤ V_n ≤ V_max
```

### SCED 如何计算 LMP？

SCED 使用**拉格朗日松弛法（Lagrangian Relaxation）** 求解：

```
构建拉格朗日函数：
L = Σ成本_i + λ₁(功率平衡约束) + Σ λ_l(线路容量约束) + ...

求解后：
  λ₁ = 系统能量价格（所有节点相同）
  λ_l（活跃约束）= 线路 l 的影子价格
       → 直接进入 LMP 的阻塞分量
```

### 影子价格（Shadow Price）

**影子价格**是理解 LMP 阻塞分量的关键：

| 情况 | 影子价格 | 含义 |
|------|---------|------|
| 线路未达容量 | λ_l = 0 | 阻塞不影响价格 |
| 线路满载（正常方向）| λ_l > 0 | 每多用 1 MW，需减负荷或启贵机 |
| 线路满载（反向）| λ_l < 0 | 反向潮流可以缓解阻塞 |

**影子价格的单位：** $/MWh per MW of constraint relief

## 金融输电权（FTR）

### FTR 的设计逻辑

LMP 的阻塞分量会导致一个问题：**如果某输电线路经常拥堵，线路一侧的用户持续支付高 LMP，这不公平。**

**解决方案：引入金融输电权（Financial Transmission Right, FTR）。**

FTR 是一种**金融衍生品**，让市场主体可以对冲 LMP 阻塞成本：

```
FTR 持有者：购买从节点 A 到节点 B 的 FTR
           （容量 1 MW，持续 1 个月）

如果：A→B 线路拥堵期间，LMP(A→B) 价差为 $20/MWh
则：FTR 持有者获得 $20 × 1MW × 运营小时 的收益

→ 相当于锁定了 A→B 的输电权价值
→ 对冲了因输电阻塞导致的价格波动风险
```

### FTR 的拍卖与分配

| 方式 | 说明 |
|------|------|
| **年度拍卖** | FERC 要求各 ISO/RTO 每年拍卖 FTR |
| **月度拍卖** | 细化到每月的 FTR 产品 |
| **长期分配** | 部分 FTR 按历史使用量分配给输电客户 |
| **点对点（P2P）** | 买卖双方直接交易 FTR |

### 阻塞收益权（CRR）

CAISO 使用"阻塞收益权"（Congestion Revenue Right, CRR），功能等同于 FTR，但名称和分配机制略有不同：
- CRR 主要通过**先到先得**和**历史分配**方式发放
- 年度/季度/月度拍卖作为补充

## 区域定价 vs 节点定价

### 两种定价体系

```
统一定价（Zonal Pricing）
  ↓
所有节点归为少数几个"区域"，区域内同价
→ 简单，但不够精确

节点定价（Nodal Pricing）
  ↓
每个物理节点单独计算 LMP
→ 精确反映真实成本，但计算复杂
```

### 关键区别

| 维度 | 区域定价 | 节点定价 |
|------|---------|---------|
| 精度 | 低（区域平均） | 高（节点级） |
| 信号准确性 | 模糊 | 精确 |
| 计算量 | 小 | 大（数万个节点） |
| 市场效率 | 较低 | 高 |
| 实施难度 | 简单 | 复杂 |
| 代表市场 | 部分欧洲市场 | PJM, CAISO, ISO-NE |

### 归堆定价（Hub Clustering）

即使是节点定价的 ISO，也会将相关节点"归堆"成虚拟枢纽（Hub），便于交易：

```
PJM 虚拟枢纽（Hubs）：
  - PJM-West Hub（西部）
  - PJM-AEP Dayton Hub（俄亥俄地区）
  - PJM-NIllinois Hub（芝加哥地区）

CAISO 归堆节点（CPN）：
  - NP15（北加州）
  - SP15（南加州）
  -ZP26（穿过Path 26）
```

## 各 ISO/RTO 的 LMP 实施

### PJM

PJM 是 LMP 的先驱，1990 年代末率先全面实施节点定价：

| 特点 | 说明 |
|------|------|
| 节点数量 | 约 80,000+ 个节点 |
| 计算频率 | 每 5 分钟 |
| 价格发布 | 实时（5 分钟）和小时平均 |
| FTR | 成熟的 FTR 市场，年度/月度拍卖 |

**PJM 的 LMP 特色：**
- 阻塞管理严格，影子价格实时公开
- FTR 市场流动性好，对冲工具成熟
- 实时 LMP 与日前 LMP 差异是市场关注焦点

### CAISO

CAISO 自 2009 年起实施 LMP（继承自 CALPX）：

| 特点 | 说明 |
|------|------|
| 节点数量 | 约 30,000 个节点 |
| LMP 分量 | 能量 + 阻塞 + 损耗 |
| 辅助服务 | 与 LMP 联合优化 |
| 鸭子曲线 | 严重影响 LMP 日内分布 |

**CAISO LMP 的日内特征（典型晴日）：**

```
00:00-06:00  低负荷 → 气电低价 → LMP 较低
06:00-12:00  负荷上升 + 太阳能介入 → LMP 适中
12:00-14:00  太阳能峰值 → 供过于求 → LMP 降至谷底
14:00-18:00  太阳能骤降 + 负荷高峰 → LMP 急剧飙升
18:00-21:00  峰值时刻 → 气电调峰机启动 → LMP 最高（可达 $200-500/MWh）
21:00-24:00  负荷下降 → LMP 回落
```

### ISO-NE

新英格兰市场结构复杂，有独立的容量市场（Forward Capacity Market, FCM）：

| 特点 | 说明 |
|------|------|
| 节点定价 | ✓ 全面实施 |
| 辅助服务市场 | 与 LMP 联合优化 |
| 容量市场 | FCM 独立于 LMP 运营 |
| 特殊情况 | 天然气管网冬季瓶颈 → 冬季 LMP 异常高 |

### MISO

MISO 覆盖 15 个州，横跨不同区域：

| 挑战 | 说明 |
|------|------|
| 区域差异 | 中西部低价煤电 vs 周边气电区 |
| 可再生能源 | 风电容纳量极大（10+ GW） |
| LMP 跨度 | $15-300/MWh 不等 |

## 节点定价与可再生能源

### 风光出力的价格影响

**低边际成本问题：**

风光发电的边际成本接近零（只要有风/光）。大量风光并网后，系统边际成本被压低：

```
风光大发时段：
  → 系统调度风光优先（ Merit Order 上移）
  → 边际机组从气电变为煤电甚至风光
  → 能量价格（Energy Component）大幅下降

→ 可能出现负电价：风光被迫削减时
  → 能量价格为负（付钱让人用电）
```

**鸭子曲线 + LMP = 极端价格波动**

```
中午：太阳能满发 + 负荷中等
  → 系统边际成本极低（LMP ≈ $10-20/MWh）
  → 阻塞分量因输电线满载仍存在

傍晚（"鸭子颈部"）：
  → 太阳能骤降 10GW（加州约 15:00-19:00）
  → 负荷急剧上升（空调 + 照明）
  → 需要 10+ GW 快速爬坡资源
  → 系统边际成本飙升（LMP ≈ $150-500/MWh）
  → 阻塞分量因输电网紧绷而放大
```

### LMP 对可再生能源投资的意义

**高 LMP 区域 = 投资信号：**

```
某区域 LMP 持续偏高（>$80/MWh）
       ↓
说明：该区域供电成本高、输电阻塞严重
       ↓
投资机会：
  1. 本地新建燃气调峰电厂（满足爬坡需求）
  2. 本地建储能（套利低买高卖）
  3. 需求响应聚合商（削减峰值负荷）
  4. 输电网扩建（缓解阻塞）
```

**负电价区 = 消纳问题：**

```
某区域出现频繁负电价
       ↓
风光弃电风险高
       ↓
投资信号：
  1. 储能（充电储存，峰时放电）
  2. 抽水蓄能（大规模储能）
  3. 需求响应（工业用户主动响应负电价）
  4. 电转气（Power-to-Gas）试点
```

### 跨区调度与 LMP 平滑

当一个区域 LMP 极高，相邻区域 LMP 较低时，跨区输电可以：
- 降低高价区的 LMP
- 提高低价区的 LMP
- 提升整体系统经济效率

这就是为什么 **FERC Order 1000** 强制要求各 ISO/RTO 建立跨区输电规划机制。

## LMP 的局限性

### 1. 计算复杂性

```
PJM: 80,000+ 节点
CAISO: 30,000+ 节点
每 5 分钟运行一次 SCED + LMP 计算

→ 对计算资源和算法要求极高
→ 需要高速通信和实时数据系统支撑
```

### 2. 价格波动性

LMP 每 5 分钟更新一次，实时市场可能剧烈波动：

```
PJM 某节点实时 LMP 极端案例：
  正常日：$30-80/MWh
  夏季峰值：$500-1,000/MWh（持续 30-60 分钟）
  紧急事件：$2,000-9,000/MWh（FERC 限价前）
```

### 3. 市场力滥用风险

拥有稀缺输电节点控制权的市场主体，可能操纵 LMP：

```
策略：持有某关键节点附近的发电容量
      → 该节点 LMP 高企
      → 获得超额利润

监管对策：
  - FERC 市场监测（Market Monitoring）
  - 容量上限（Offer Caps）
  - 关键供应商认定（Must-Run Designation）
```

### 4. 不完全信息

SCED 依赖准确的负荷预测和发电报价，但：
- 可再生能源出力预测有误差
- 负荷预测有偏差
- 市场主体可能策略性报价

→ 导致 LMP 与真实边际成本存在偏差

## 节点定价的操作实例

### 一个完整出清周期

```
T-1 13:00  CAISO 运行日前 SCUC + SCED
           → 生成次日 24 小时 LMP 曲线
           → 发布各节点日前价格

T 14:55   CAISO 运行实时 SCED（每 5 分钟一次）
           → 当前调度窗口：T+5min 到 T+10min
           → 根据最新负荷/发电/输电数据
           → 求解最优发电计划
           → 计算各节点实时 LMP

T 15:00   发布节点 P 的实时 LMP：
           能量分量 $48.30/MWh
           阻塞分量 $7.20/MWh
           损耗分量 $0.95/MWh
           ─────────────────────
           LMP = $56.45/MWh

T+1 Day   月底结算：
           买方：按 LMP × 实际负荷 结算
           卖方：按 LMP × 实际发电 结算
           FTR 持有者：获得阻塞价差收益
```

## 相关概念

- **LMP：** Locational Marginal Pricing（节点边际电价）
- **SCED：** Security Constrained Economic Dispatch（安全约束经济调度）
- **SCUC：** Security Constrained Unit Commitment（安全约束机组组合）
- **FTR：** Financial Transmission Right（金融输电权）
- **CRR：** Congestion Revenue Right（阻塞收益权，CAISO 术语）
- **Shadow Price：** 影子价格，约束的边际价值
- **Congestion：** 输电阻塞
- **Loss：** 输电损耗
- **Merit Order：** 发电优先级排序（按边际成本从低到高）
- **Hub：** 虚拟枢纽，多个节点归堆后的价格参考点
- **Bid/Offer：** 投标/报价
