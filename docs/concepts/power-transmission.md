# 输电 (Power Transmission)

输电是将电力从发电厂输送到变电站的过程，使用高压线路跨越长距离。

## 为什么需要高压输电？

**物理原理**: 电力传输中的损耗与电流的平方成正比（P = I²R）
- 电压越高 → 电流越低 → 损耗越少
- 高压输电更高效，成本更低

典型输电电压: 115kV - 765kV

## 输电基础设施

### 输电线路
- **高压线路**: 架设在高塔上，跨越数百英里
- **直流 vs 交流**: 大多数是交流 (AC)，部分长距离使用直流 (HVDC)

### 变电站 (Substations)
- 连接不同电压等级的线路
- 安装变压器、断路器、保护设备
- 电力系统的"枢纽"

## 关键概念

| 术语 | 定义 |
|------|------|
| 输电网 | 运输电力的高速公路 |
| 调度中心 | 监控和控制输电网 |
| PJM, MISO, ISO-NE 等 | 区域输电组织 (RTO/ISO) |
| 平衡机构 | 确保供电与需求实时匹配 |
